## 💻 Sobre o Projeto

Este repositório hospeda meu portfólio profissional e acadêmico, desenvolvido como projeto final da disciplina de **BootCamp I** no curso superior de **Ciência da Computação (UniCEUB)**. 

A interface foi totalmente inspirada em uma Linha de Comando (CLI) Unix, simulando o visual clássico do sistema **Arch Linux**. O objetivo principal é consolidar minha identidade como desenvolvedor no início da graduação e aplicar as ferramentas do **Google Workspace** na concepção e planejamento do projeto.

🌐 **Acesse o portfólio ao vivo:** [biroveyou.github.io/github-page/](https://biroveyou.github.io/github-page/)

---

## 🛠️ Especificações do Sistema (Stack Tecnológica)

*   **Front-end Semântico:** HTML5 estruturado e CSS3 responsivo (customizado com fontes monoespaçadas, efeitos visuais e paleta terminal *green-phosphor*).
*   **Gestão de Conteúdo (Google Workspace):** 
    *   **Google Docs:** Utilizado como ambiente de staging para redação técnica, refinamento textual e estruturação semântica de todos os módulos e blocos textuais antes da codificação.
*   **Hospedagem e CI/CD:** GitHub Pages com entrega contínua automatizada a cada integração na branch principal.
