## 💻 Sobre o Projeto

Este repositório hospeda meu portfólio profissional e acadêmico, desenvolvido como projeto final da disciplina de **BootCamp I** no curso superior de **Ciência da Computação (UniCEUB)**. 

A interface foi totalmente inspirada em uma Linha de Comando (CLI) Unix, simulando o visual clássico do sistema **Arch Linux**. O objetivo principal é consolidar minha identidade como desenvolvedor e integrar de forma prática o desenvolvimento front-end com o ecossistema de dados do **Google Workspace**.

🌐 **Acesse o portfólio ao vivo:** [biroveyou.github.io/github-page/](https://biroveyou.github.io/github-page/)

---

## 🛠️ Especificações do Sistema (Stack Tecnológica)

*   **Front-end Semântico:** HTML5 estruturado e CSS3 responsivo (customizado com fontes monoespaçadas e paleta terminal *green-phosphor*).
*   **Camada de Dados (Google Workspace):** 
    *   **Google Docs:** Planejamento e validação textual dos módulos.
    *   **Google Sheets + Apps Script:** Banco de dados dinâmico que processa e armazena as mensagens enviadas pelo formulário de contato em tempo real.
*   **Hospedagem e CI/CD:** GitHub Pages com deploys automatizados a cada merge na branch principal.
